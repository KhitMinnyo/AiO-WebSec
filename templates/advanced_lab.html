Server-Side Template Injection (SSTI)

This occurs when user input is directly passed into the template engine (Jinja2) for generating greeting messages. (e.g., try entering {{ 7*7 }} as input)

XML External Entity (XXE) Injection

This occurs when the XML parser allows external entities. Try reading local files (e.g., /etc/passwd).

Deserialization of Untrusted Data (YAML)

Code execution can occur when user-supplied serialized data (**YAML** in this lab) is deserialized insecurely.

Try creating Python objects using a YAML payload. (Works only at Low Level)
