🛡️ AIO-WebSec: All-in-One Vulnerability Lab

This is a ready-to-use sandbox for you to improve your **Ethical Hacking** skills by attacking and defending an insecure web application.

"Attack. Analyze. Secure. Repeat."

🔥 Challenges You Will Face in This Lab

  • Injection Attacks: Break server logic using SQLi, XSS, CmdI, SSTI, etc.
  • Access Control Flaws: Steal other users' data using IDOR, CSRF, etc.
  • Logic & SSRF: Bypass payment logic and scan the internal network.

⚙️ Changing Security Level (Defense Control)

You can change the difficulty of vulnerabilities using the **Security Level Selector** at the top of the lab. By switching levels, you can **compare and learn** between vulnerable and secure code.

Level Vulnerability State What You Can Learn
0 (Low) ❌ Highly Vulnerable Practice basic attack techniques from scratch.
1 (Medium) ⚠️ Filtered / Bypassable Learn basic **bypass** techniques and how to distinguish filters.
2 (High) ✅ Secure **Study** defensive code (e.g., prepared statements).
